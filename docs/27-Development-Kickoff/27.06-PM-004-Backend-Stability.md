# PM-004 — تثبيت Backend قبل بناء الواجهات

**الإصدار:** v1.3.0  
**التاريخ:** 2026-07-24  
**الحالة:** مدمج في المصدر

## نطاق الدمج

يخص هذا القرار تطبيق NestJS الموجود في `apps/api` فقط. لا يستبدل خدمة
`artifacts/api-server` الحالية المبنية على Express وDrizzle.

## التعديلات المصدرية

| الملف | التعديل |
|---|---|
| `apps/api/package.json` | استبدال `bcrypt` بـ `bcryptjs`، وإضافة `@types/bcryptjs`، وتثبيت أمر التشغيل بمسارين |
| `apps/api/src/modules/auth/password.service.ts` | استخدام `bcryptjs` مع الإبقاء على واجهة `hash` و`verify` |
| `apps/api/Dockerfile` | تشغيل Prisma ثم تجربة `dist/main.js` و`dist/src/main.js` |

## قواعد التشغيل

```bash
cd apps/api
npm install
npx prisma generate
npx prisma db push
npm run prisma:seed
npm run start:dev
```

## عناصر مستبعدة من الدمج البرمجي

- صفحة HTML الخاصة بلوحة حالة الحزمة.
- النصوص الخطابية والتوضيحية وطلبات الإيصال.
- تعديل `.replit` أو `replit.nix` أو `package.json` الجذري، لأنها لا تطابق بنية
  مساحة العمل الحالية.
- إنشاء مسارات `apps/web` و`apps/admin` جديدة؛ تبقى ضمن مراحلها الموثقة.
