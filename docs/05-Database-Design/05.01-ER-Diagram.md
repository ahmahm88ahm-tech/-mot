## 2. ملخص العلاقات

| العلاقة | النوع | الوصف |
|--------|------|------|
| Region → Cities | 1:N | المنطقة تحتوي مدن |
| City → Districts | 1:N | المدينة تحتوي أحياء |
| City → Branches | 1:N | المدينة تحتوي فروع |
| User → Orders | 1:N | المستخدم له طلبات |
| User → Reviews | 1:N | المستخدم له تقييمات |
| User → Notifications | 1:N | المستخدم له إشعارات |
| User → Activities | 1:N | المستخدم له أنشطة |
| Branch → Orders | 1:N | الفرع له طلبات |
| Service → Orders | 1:N | الخدمة لها طلبات |
| Order → OrderImages | 1:N | الطلب له صور |
| Order → StatusHistory | 1:N | الطلب له سجل حالات |
| Order → Reviews | 1:N | الطلب له تقييمات |
| Role → Permissions | N:M | الأدوار والصلاحيات |
| User → Roles | N:M | المستخدمين والأدوار |
| Menu → MenuItems | 1:N | القائمة لها عناصر |
| Slider → SliderItems | 1:N | السلايدر له عناصر |
