## Endpoint تأكيد الدفع
```
PATCH /api/v1/orders/:id/payment
Authorization: Bearer <admin_token>

Body: { "method": "BANK_TRANSFER", "reference": "TXN-88412" }
       { "method": "CASH" }

Responses:
  200  Order مُحدَّث (paymentStatus: PAID)
  400  الطلب مدفوع مسبقاً
  403  صلاحيات غير كافية
  404  الطلب غير موجود
```

## صلاحيات confirmPayment
| الدور | CASH | BANK_TRANSFER |
|-------|:----:|:-------------:|
| ADMIN / MANAGER / SUPER_ADMIN | ✅ | ✅ |
| DRIVER / EMPLOYEE (معيَّن للطلب) | ✅ | ❌ |
| CUSTOMER | ❌ | ❌ |

## ملاحظة Schema
إن لم تكن حقول `paymentStatus / paymentRef / paidAt / paidBy` في `prisma/schema.prisma` أضفها اختيارية ثم شغّل `prisma db push`. لا تكسر البناء لأن الحقول optional.

## PWA — خطوات التشغيل
1. `apps/web/public/sw.js` — في مكانه (Next يخدمه من `public/` مباشرة)
