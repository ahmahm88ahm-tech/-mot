# قائمة الإطلاق (GO-LIVE) — وقّع قبل أول عميل حقيقي

> لا يُفتح الإطلاق التجريبي حتى تُعلَّم كل خانة ويوقَّع أدناه. هذه ليست قائمة تُشطَب، بل عتباتٌ تُغلق بدليل.

## أ. تقني
- [ ] `npm test` و `npx playwright test` أخضران محلياً وعلى CI.
- [ ] `/api/v1/health` = 200 على الدومين الإنتاجي (HTTPS، قفل أخضر).
- [ ] `/status` (بمشرف) = all green؛ قاعدة البيانات متصلة.
- [ ] متغيرات الإنتاج مضبوطة، و`deploy-check.sh` أخضر.
- [ ] النسخ الاحتياطي مُستعاد بنجاح على بيئة منفصلة (drill).

## ب. تشغيلي
- [ ] SOP مُوقَّع من كل دور؛ القوالب مجرّبة.
- [ ] مُؤكِّد التحويل مدرّب؛ إجراء الشكاوى مُجرّب بحادثة وهمية.
- [ ] أوقات التغطية معلنة؛ الرد الآلي خارجها مفعّل.

## ج. قانوني / مالي
- [ ] `ZATCA_VAT_NUMBER` حقيقي؛ QR مجتاز بفاحص زكوي.
- [ ] بوليصة تأمين سارية؛ نص `/guarantee` مطابق لها.
- [ ] `/privacy-policy` و`/terms` منشوران ومربوطان في الفوتر.
- [ ] سجل تجاري ساري بنشاط النقل.

## د. تسويقي / إطلاق
- [ ] أول 5–10 عملاء تجريبيين محدّدون + حافز + قناة feedback.
- [ ] قناة مراقبة مفتوحة يوم الإطلاق (الشخص + المنصّة).
- [ ] زرّ تراجع واضح: من يُوقف الإعلان إن ظهر عطل.
