## 1. نظرة عامة على نظام الإشعارات

### 1.1 الغرض

نظام الإشعارات في MOTANAQIL هو نظام مركزي متعدد القنوات يُدير جميع الاتصالات بين النظام والمستخدمين (عملاء، موظفين، إدارة) بطريقة:

- **موثوقة:** ضمان وصول الإشعارات
- **قابلة للتتبع:** معرفة حالة كل إشعار
- **قابلة للتخصيص:** قوالب ديناميكية
- **متعددة اللغات:** عربي وإنجليزي
- **قابلة للتوسع:** دعم قنوات جديدة مستقبلاً

### 1.2 المبادئ الأساسية

✅ **Event-Driven Architecture** — الإشعارات تُرسل استجابة لأحداث  
✅ **Asynchronous Processing** — معالجة غير متزامنة عبر الطوابير  
✅ **Multi-Channel Support** — دعم 5 قنوات مختلفة  
✅ **Template-Based** — جميع الإشعارات من قوالب قابلة للتعديل  
✅ **User Preferences** — احترام تفضيلات المستخدم  
✅ **Delivery Tracking** — تتبع حالة التسليم  
✅ **Retry Mechanism** — إعادة المحاولة عند الفشل  
✅ **Rate Limiting** — منع الإزعاج (Anti-Spam)

### 1.3 المستخدمون المستهدفون

| المستخدم | القنوات المستخدمة | الأمثلة |
|---------|------------------|---------|
| **العميل** | Email, SMS, WhatsApp, Push, In-App | تأكيد الطلب، تتبع السائق |
| **الموظف/السائق** | Push, SMS, WhatsApp, In-App | تعيين طلب جديد، تحديث حالة |
| **المدير** | Email, Push, In-App | طلب جديد، تنبيهات حرجة |
| **Super Admin** | Email, In-App | تنبيهات النظام، الأمان |

### 2.3 مبادئ التصميم

#### 2.3.1 مبدأ الفصل بين المسؤوليات

```typescript
// Notification Service لا يرسل مباشرة
// بل يضع الإشعار في الطابور المناسب

class NotificationService {
  async send(notification: NotificationRequest) {
    // 1. التحقق من التفضيلات
    if (!this.userWantsChannel(notification.userId, notification.channel)) {
      return { skipped: true, reason: 'user_preference' };
    }
    
    // 2. التحقق من Rate Limiting
    if (await this.rateLimiter.isLimited(notification.userId, notification.channel)) {
      return { skipped: true, reason: 'rate_limited' };
    }
    
    // 3. معالجة القالب
    const content = await this.templateEngine.render(
      notification.templateId,
      notification.variables,
      notification.language
    );
    
    // 4. إضافة للطابور
    await this.queueManager.enqueue(notification.channel, {
      ...notification,
      content,
    });
    
    // 5. تسجيل في قاعدة البيانات
    return await this.notificationRepo.create({
      ...notification,
      status: 'queued',
    });
  }
}
```

#### 2.3.2 مبدأ المرونة في المزودين

```typescript
// Strategy Pattern لمزودي الخدمة
interface EmailProvider {
  send(email: EmailMessage): Promise<DeliveryResult>;
  getStatus(messageId: string): Promise<DeliveryStatus>;
}

class SendGridProvider implements EmailProvider { ... }
class AWSSESProvider implements EmailProvider { ... }
class MailgunProvider implements EmailProvider { ... }

// الفشل التلقائي (Failover)
class EmailProviderManager {
  async send(email: EmailMessage): Promise<DeliveryResult> {
    const providers = [this.sendgrid, this.awsSes, this.mailgun];
    
    for (const provider of providers) {
      try {
        return await provider.send(email);
      } catch (error) {
        this.logger.warn(`Provider ${provider.name} failed`, error);
        continue;
      }
    }
    
    throw new Error('All email providers failed');
  }
}
```

### 3.3 قواعد اختيار القناة

```typescript
function selectChannel(
  notification: NotificationRequest,
  userPreferences: UserPreferences
): Channel[] {
  const priority = channelPriority[notification.type];
  const enabledChannels = userPreferences.notifications;
  
  // فلترة القنوات المفعلة من قبل المستخدم
  const availableChannels = priority.filter(
    channel => enabledChannels[channel] !== false
  );
  
  // احترام "Do Not Disturb"
  if (userPreferences.doNotDisturb && !notification.isUrgent) {
    return ['in_app']; // فقط داخل التطبيق
  }
  
  // احترام ساعات الصمت
  if (isInQuietHours(userPreferences) && !notification.isUrgent) {
    return scheduleForMorning(availableChannels);
  }
  
  return availableChannels;
}
```

## 5. نظام القوالب

### 5.1 هيكل القالب

```typescript
interface NotificationTemplate {
  id: string;
  code: string;              // مثل: order.confirmed.sms
  event: string;             // مثل: order.confirmed
  channel: Channel;          // email, sms, whatsapp, push, in_app
  language: 'ar' | 'en';
  
  // المحتوى
  subject?: string;          // للبريد الإلكتروني
  title: string;             // للعنوان (Push, In-App, WhatsApp)
  body: string;              // المحتوى الرئيسي
  htmlBody?: string;         // للبريد الإلكتروني (HTML)
  
  // التخصيص
  variables: TemplateVariable[];
  
  // CTA
  ctaButton?: {
    text: string;
    url: string;
  };
  
  // الوسائط
  imageUrl?: string;
  iconUrl?: string;
  
  // المزود
  providerTemplateId?: string; // مثل WhatsApp Template ID
  
  // الحالة
  isActive: boolean;
  version: number;
  
  createdAt: Date;
  updatedAt: Date;
}

interface TemplateVariable {
  name: string;              // مثل: customerName
  type: 'string' | 'number' | 'date' | 'url';
  required: boolean;
  defaultValue?: string;
  description: string;
  example: string;
}
```

```typescript
// template-engine.service.ts
import Handlebars from 'handlebars';
import { format } from 'date-fns';
import { ar, enUS } from 'date-fns/locale';

@Injectable()
export class TemplateEngineService {
  constructor(private readonly templateRepo: TemplateRepository) {
    this.registerHelpers();
  }

  private registerHelpers() {
    // تنسيق التاريخ
    Handlebars.registerHelper('formatDate', (date, formatStr, lang) => {
      const locale = lang === 'ar' ? ar : enUS;
      return format(new Date(date), formatStr, { locale });
    });

    // تنسيق العملة
    Handlebars.registerHelper('formatCurrency', (amount, currency = 'SAR') => {
      return new Intl.NumberFormat('ar-SA', {
        style: 'currency',
        currency,
      }).format(amount);
    });

    // تنسيق الرقم
    Handlebars.registerHelper('formatNumber', (num) => {
      return new Intl.NumberFormat('ar-SA').format(num);
    });

    // شرط
    Handlebars.registerHelper('ifEquals', function (a, b, options) {
      return a === b ? options.fn(this) : options.inverse(this);
    });
  }

  async render(
    templateCode: string,
    variables: Record<string, any>,
    language: 'ar' | 'en' = 'ar'
  ): Promise<RenderedContent> {
    // 1. جلب القالب
    const template = await this.templateRepo.findByCodeAndLanguage(
      templateCode,
      language
    );

    if (!template) {
      throw new Error(`Template not found: ${templateCode}`);
    }

    // 2. التحقق من المتغيرات المطلوبة
    this.validateVariables(template.variables, variables);

    // 3. تجميع القالب
    const compiledSubject = template.subject
      ? Handlebars.compile(template.subject)
      : null;
    const compiledTitle = Handlebars.compile(template.title);
    const compiledBody = Handlebars.compile(
      template.htmlBody || template.body
    );

    // 4. التصيير
    return {
      subject: compiledSubject ? compiledSubject(variables) : undefined,
      title: compiledTitle(variables),
      body: compiledBody(variables),
      ctaButton: template.ctaButton
        ? {
            text: Handlebars.compile(template.ctaButton.text)(variables),
            url: Handlebars.compile(template.ctaButton.url)(variables),
          }
        : undefined,
    };
  }

  private validateVariables(
    templateVars: TemplateVariable[],
    providedVars: Record<string, any>
  ) {
    for (const v of templateVars) {
      if (v.required && !(v.name in providedVars)) {
        throw new Error(`Missing required variable: ${v.name}`);
      }
    }
  }
}
```

```typescript
// email.processor.ts
@Processor(QUEUE_NAMES.EMAIL_HIGH)
export class EmailHighProcessor {
  constructor(
    private readonly emailProvider: EmailProviderManager,
    private readonly notificationRepo: NotificationRepository,
    private readonly deliveryLogRepo: DeliveryLogRepository,
  ) {}

  @Process()
  async processEmail(job: Job<NotificationJob>) {
    const { notificationId, content, recipient } = job.data;

    // 1. تحديث الحالة إلى "sending"
    await this.notificationRepo.updateStatus(notificationId, 'sending');

    try {
      // 2. إرسال البريد
      const result = await this.emailProvider.send({
        to: recipient.email,
        subject: content.subject,
        html: content.body,
        from: 'noreply@motanaqil.com',
        fromName: 'مُتنقِّل',
      });

      // 3. تسجيل التسليم
      await this.deliveryLogRepo.create({
        notificationId,
        channel: 'email',
        provider: result.provider,
        providerMessageId: result.messageId,
        status: 'sent',
        sentAt: new Date(),
      });

      // 4. تحديث الحالة
      await this.notificationRepo.updateStatus(notificationId, 'sent');

      return { success: true, messageId: result.messageId };
    } catch (error) {
      // 5. تسجيل الفشل
      await this.deliveryLogRepo.create({
        notificationId,
        channel: 'email',
        status: 'failed',
        error: error.message,
        failedAt: new Date(),
      });

      // 6. إعادة المحاولة أو الفشل النهائي
      if (job.attemptsMade < job.opts.attempts) {
        throw error; // BullMQ سيعيد المحاولة
      } else {
        await this.notificationRepo.updateStatus(notificationId, 'failed');
      }
    }
  }

  @OnQueueFailed()
  async onFailed(job: Job, error: Error) {
    this.logger.error(`Job ${job.id} failed:`, error);
    // إرسال تنبيه للإدارة إذا فشل إشعار حرج
    if (job.data.priority === 'critical') {
      await this.alertAdmin(job.data, error);
    }
  }
}
```

```typescript
// notifications.gateway.ts
@WebSocketGateway({
  namespace: '/notifications',
  cors: { origin: process.env.FRONTEND_URL },
})
export class NotificationsGateway {
  @WebSocketServer()
  server: Server;

  constructor(
    private readonly authService: AuthService,
    private readonly notificationService: NotificationService,
  ) {}

  async handleConnection(client: Socket) {
    const token = client.handshake.auth.token;
    const user = await this.authService.validateToken(token);
    
    if (!user) {
      client.disconnect();
      return;
    }
    
    client.join(`user:${user.id}`);
    client.join(`role:${user.role}`);
    
    // إرسال الإشعارات غير المقروءة
    const unread = await this.notificationService.getUnread(user.id);
    client.emit('notifications:unread_count', unread.length);
  }

  // إرسال إشعار فوري
  sendToUser(userId: string, notification: InAppNotification) {
    this.server.to(`user:${userId}`).emit('notification:new', notification);
    this.server.to(`user:${userId}`).emit('notifications:unread_count', notification.totalUnread);
  }

  // إرسال لجميع المدراء
  sendToRole(role: string, notification: InAppNotification) {
    this.server.to(`role:${role}`).emit('notification:new', notification);
  }

  // بث عام (للصيانة مثلاً)
  broadcast(notification: InAppNotification) {
    this.server.emit('notification:broadcast', notification);
  }
}
```

```typescript
// unifonic.provider.ts
import axios from 'axios';

@Injectable()
export class UnifonicProvider implements SMSProvider {
  private readonly baseUrl = 'https://api.unifonic.com/rest';
  private readonly appKey = process.env.UNIFONIC_APP_KEY;
  private readonly senderId = process.env.UNIFONIC_SENDER_ID; // "Motanaqil"

  async send(sms: SMSMessage): Promise<DeliveryResult> {
    const response = await axios.post(
      `${this.baseUrl}/SMS/messages`,
      new URLSearchParams({
        AppKey: this.appKey,
        SenderID: this.senderId,
        Recipient: sms.to.replace('+', ''),
        Body: sms.body,
        msgType: 'text',
        timeSent: sms.scheduledAt?.toISOString() || '0',
      }),
      {
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      }
    );

    if (response.data.success === 'false') {
      throw new Error(response.data.message);
    }

    return {
      provider: 'unifonic',
      messageId: response.data.MessageID,
      status: 'sent',
      cost: response.data.Cost,
    };
  }

  async getStatus(messageId: string): Promise<DeliveryStatus> {
    const response = await axios.get(
      `${this.baseUrl}/SMS/getMessageStatus`,
      {
        params: {
          AppKey: this.appKey,
          MessageID: messageId,
        },
      }
    );

    return this.mapStatus(response.data.Status);
  }
}
```

```typescript
      recipient_type: 'individual',
      to: message.to,
      type: 'template',
      template: {
        name: message.templateName,
        language: { code: message.language === 'ar' ? 'ar' : 'en_US' },
        components: [
          {
            type: 'body',
            parameters: message.variables.map(v => ({
              type: 'text',
              text: String(v),
            })),
          },
          ...(message.buttons ? [{
            type: 'button',
            sub_type: 'url',
            index: 0,
            parameters: [{ type: 'text', text: message.buttons[0].urlSuffix }],
          }] : []),
        ],
      },
    };

    const response = await axios.post(
      `${this.baseUrl}/${this.phoneId}/messages`,
      payload,
      {
        headers: {
          Authorization: `Bearer ${this.accessToken}`,
          'Content-Type': 'application/json',
        },
      }
    );

    return {
      provider: 'whatsapp',
      messageId: response.data.messages[0].id,
      status: 'sent',
    };
  }

        header: {
          type: 'image',
          image: { link: message.image },
        },
        body: { text: message.body },
        action: {
          buttons: message.buttons.map((btn, i) => ({
            type: 'reply',

      `${this.baseUrl}/${this.phoneId}/messages`,

        },
      }
    );

      messageId: response.data.messages[0].id,
      status: 'sent',
    };
  }
}
```

```typescript
function applyQuietHours(
  scheduledAt: Date,
  preferences: NotificationPreferences
): Date {
  if (!preferences.quietHours.enabled) return scheduledAt;
  
  const tz = preferences.quietHours.timezone;
  const start = parseTime(preferences.quietHours.startTime, tz);
  const end = parseTime(preferences.quietHours.endTime, tz);
  
  if (isInTimeRange(scheduledAt, start, end, tz)) {
    // تأجيل لنهاية ساعات الصمت
    return getNextOccurrence(end, tz);
  }
  
  return scheduledAt;
}
```
