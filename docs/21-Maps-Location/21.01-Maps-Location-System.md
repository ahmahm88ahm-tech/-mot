## 1. نظرة عامة على نظام الخرائط

### 1.1 الغرض

نظام الخرائط والموقع في MOTANAQIL مصمم لتحقيق **دقة احترافية عالية** تضمن:

- 🎯 **وصول السائق للموقع بدقة** حتى في الأحياء المعقدة والمباني المتشابهة
- 📍 **تحديد دقيق لموقع الاستلام والتسليم** (حتى الطابق والمدخل)
- 🚚 **تتبع السائق لحظياً** مع ETA دقيق
- 🛣️ **حساب المسارات المثلى** مع مراعاة الزحام والطرق المغلقة
- 📏 **حساب المسافات بدقة** للتسعير العادل
- 🔔 **كشف الوصول تلقائياً** عبر Geofencing
- 🌐 **دعم كامل للسعودية** مع بيانات الأحياء والشوارع

### 1.2 التحديات الخاصة بالسعودية

✅ **الأحياء الجديدة** التي قد لا تظهر في بعض الخرائط  
✅ **المباني المتشابهة** في المجمعات السكنية  
✅ **العناوين الوطنية** (نظام العنوان الوطني السعودي)  
✅ **اللغة العربية** في البحث والعرض  
✅ **الاتجاه من اليمين لليسار** (RTL) في الواجهة  
✅ **مناطق بدون تغطية GPS جيدة** (أنفاق، مباني عالية)  
✅ **الزحام المروري** في أوقات الذروة (الرياض، جدة)

### 1.3 المبادئ الأساسية

✅ **Accuracy First** — الدقة أولاً، حتى لو كلفت موارد أكثر  
✅ **Multi-Source Fusion** — دمج GPS + WiFi + Cell + Sensors  
✅ **Snap-to-Road** — ربط الموقع بالطريق الفعلي  
✅ **User Confirmation** — تأكيد العميل للموقع  
✅ **Real-time Sync** — مزامنة فورية بين السائق والعميل والإدارة  
✅ **Graceful Degradation** — عمل مقبول عند ضعف الإشارة  
✅ **Privacy by Design** — حماية بيانات الموقع

## 5. Geocoding و Reverse Geocoding

### 5.1 Geocoding Service

```typescript
// geocoding.service.ts
@Injectable()
export class GeocodingService {
  constructor(
    private readonly googleMaps: GoogleMapsService,
    private readonly cache: RedisService,
    private readonly districtsRepo: DistrictsRepository,
  ) {}

  /**
   * تحويل عنوان نصي إلى إحداثيات
   * مع تحسينات للسعودية
   */
  async geocode(params: GeocodeParams): Promise<GeocodeResult> {
    const { address, city, district, bounds } = params;
    
    // 1. التحقق من الكاش
    const cacheKey = `geocode:${hash(address + city + district)}`;
    const cached = await this.cache.get(cacheKey);
    if (cached) return JSON.parse(cached);
    
    // 2. البحث في البيانات المحلية أولاً (أسرع وأرخص)
    const localResult = await this.searchLocal(address, city, district);
    if (localResult && localResult.confidence > 0.9) {
      return localResult;
    }
    
    // 3. استدعاء Google Geocoding مع تحسينات
    const response = await this.googleMaps.geocode({
      address: this.buildFullAddress(address, city, district),
      bounds: bounds || this.getSaudiArabiaBounds(),
      language: 'ar',
      region: 'SA', // Bias للسعودية
      components: {
        country: 'SA',
      },
    });
    
    if (!response.results.length) {
      throw new NotFoundException('Address not found');
    }
    
    // 4. اختيار أفضل نتيجة
    const bestResult = this.selectBestResult(response.results, {
      city, district,
    });
    
    // 5. تحليل المكونات
    const parsed = this.parseAddressComponents(
      bestResult.address_components
    );
    
    const result: GeocodeResult = {
      coordinates: {
        latitude: bestResult.geometry.location.lat,
        longitude: bestResult.geometry.location.lng,
      },
      accuracy: this.mapLocationTypeToAccuracy(
        bestResult.geometry.location_type
      ),
      formattedAddress: bestResult.formatted_address,
      components: parsed,
      placeId: bestResult.place_id,
      locationType: bestResult.geometry.location_type,
      confidence: this.calculateConfidence(bestResult),
    };
    
    // 6. حفظ في الكاش (24 ساعة)
    await this.cache.set(cacheKey, JSON.stringify(result), 86400);
    
    return result;
  }

  /**
   * بناء عنوان كامل محسّن للسعودية
   */
  private buildFullAddress(
    address: string,
    city?: string,
    district?: string
  ): string {
    const parts = [address];
    if (district) parts.push(district);
    if (city) parts.push(city);
    parts.push('المملكة العربية السعودية');
    return parts.filter(Boolean).join('، ');
  }

  /**
   * حدود السعودية لتحسين النتائج
   */
  private getSaudiArabiaBounds() {
    return {
      south: 16.3475,
      west: 34.6314,
      north: 32.1583,
      east: 55.6667,
    };
  }

  /**
   * تحليل مكونات العنوان
   */
  private parseAddressComponents(components: any[]): ParsedAddress {
    const get = (type: string) =>
      components.find(c => c.types.includes(type))?.long_name;
    const getShort = (type: string) =>
      components.find(c => c.types.includes(type))?.short_name;

    return {
      streetNumber: get('street_number'),
      route: get('route'),
      neighborhood: get('neighborhood') || get('sublocality_level_2'),
      district: get('sublocality_level_1') || get('sublocality'),
      city: get('locality'),
      region: get('administrative_area_level_1'),
      country: get('country'),
      postalCode: get('postal_code'),
      plusCode: get('plus_code'),
    };
  }

  /**
   * حساب الثقة في النتيجة
   */
  private calculateConfidence(result: any): number {
    let confidence = 0.5;
    
    // ROOFTOP = دقة عالية جداً
    if (result.geometry.location_type === 'ROOFTOP') confidence += 0.4;
    else if (result.geometry.location_type === 'RANGE_INTERPOLATED') confidence += 0.3;
    else if (result.geometry.location_type === 'GEOMETRIC_CENTER') confidence += 0.1;
    
    // وجود رقم الشارع يزيد الثقة
    if (result.address_components.some(c => c.types.includes('street_number'))) {
      confidence += 0.1;
    }
    
    return Math.min(confidence, 1.0);
  }
}
```

### 5.2 Reverse Geocoding

```typescript
/**
 * تحويل إحداثيات إلى عنوان
 */
async reverseGeocode(
  lat: number,
  lng: number,
  language: 'ar' | 'en' = 'ar'
): Promise<ReverseGeocodeResult> {
  const cacheKey = `revgeo:${lat.toFixed(6)}:${lng.toFixed(6)}`;
  const cached = await this.cache.get(cacheKey);
  if (cached) return JSON.parse(cached);

  const response = await this.googleMaps.reverseGeocode({
    latlng: { lat, lng },
    language,
    resultType: ['street_address', 'premise', 'subpremise'],
    locationType: ['ROOFTOP', 'RANGE_INTERPOLATED', 'GEOMETRIC_CENTER'],
  });

  if (!response.results.length) {
    throw new NotFoundException('No address found for coordinates');
  }

  const result = response.results[0];
  const parsed = this.parseAddressComponents(result.address_components);

  // ربط بالحي والمدينة في قاعدة البيانات
  const district = await this.districtsRepo.findByCoordinates(lat, lng);
  const city = district
    ? await this.citiesRepo.findById(district.cityId)
    : await this.citiesRepo.findByCoordinates(lat, lng);

  const reverseResult: ReverseGeocodeResult = {
    coordinates: { latitude: lat, longitude: lng },
    formattedAddress: result.formatted_address,
    components: parsed,
    placeId: result.place_id,
    plusCode: result.plus_code?.global_code,
    district: district ? {
      id: district.id,
      nameAr: district.nameAr,
      slug: district.slug,
    } : null,
    city: city ? {
      id: city.id,
      nameAr: city.nameAr,
      slug: city.slug,
    } : null,
    locationType: result.geometry.location_type,
  };

  await this.cache.set(cacheKey, JSON.stringify(reverseResult), 86400);
  return reverseResult;
}
```

```typescript
    watchUntilStable: boolean;
    stabilityThreshold: number;

        (position) => {
```

```typescript
// services/driver-location.service.ts (Mobile App)
// خدمة تتبع موقع السائق في الخلفية بدقة عالية

class DriverLocationService {
  private watchId: number | null = null;
  private lastSentLocation: Coordinates | null = null;
  private lastSentTime: number = 0;
  private socket: Socket | null = null;

  /**
   * بدء التتبع المستمر
   */
  async startTracking(orderId: string) {
    // 1. الاتصال بـ WebSocket
    this.socket = io(process.env.API_URL + '/tracking', {
      auth: { token: await getToken(), orderId },
    });

    // 2. طلب صلاحيات الموقع في الخلفية
    await this.requestBackgroundPermission();

    // 3. بدء التتبع بدقة عالية
    this.watchId = navigator.geolocation.watchPosition(
      (position) => this.handlePosition(position, orderId),
      (error) => this.handleError(error),
      {
        enableHighAccuracy: true,
        timeout: 30000,
        maximumAge: 1000,  // كاش ثانية واحدة فقط
      }
    );

    // 4. Foreground Service (Android) لمنع إيقاف التتبع
    if (isAndroid()) {
      await this.startForegroundService(orderId);
    }
  }

  /**
   * معالجة كل قراءة موقع
   */
  private async handlePosition(position: GeolocationPosition, orderId: string) {
    const coords: Coordinates = {
      latitude: position.coords.latitude,
      longitude: position.coords.longitude,
      accuracy: position.coords.accuracy,
      altitude: position.coords.altitude || undefined,
      heading: position.coords.heading || undefined,
      speed: position.coords.speed || undefined,
      timestamp: position.timestamp,
    };

    // 1. فلترة القراءات السيئة
    if (!this.isValidReading(coords)) {
      console.warn('Invalid GPS reading, skipping');
      return;
    }

    // 2. Snap-to-Road (ربط بالطريق)
    const snapped = await this.snapToRoad(coords);

    // 3. تطبيق خوارزمية تقليل الإرسال (لتوفير البطارية والبيانات)
    if (!this.shouldSend(snapped)) {
      return;
    }

    // 4. إرسال عبر WebSocket
    this.socket?.emit('driver:location', {
      orderId,
      coordinates: snapped,
      battery: await this.getBatteryLevel(),
      networkType: await this.getNetworkType(),
    });

    // 5. حفظ محلياً (للعمل بدون إنترنت)
    await this.saveLocally(snapped, orderId);

    this.lastSentLocation = snapped;
    this.lastSentTime = Date.now();
  }

  /**
   * التحقق من صحة القراءة
   */
  private isValidReading(coords: Coordinates): boolean {
    // تجاهل القراءات بدقة سيئة جداً
    if (coords.accuracy && coords.accuracy > 100) return false;
    
    // تجاهل القراءات المستحيلة (سرعة > 200 كم/س)
    if (coords.speed && coords.speed > 55) return false; // 55 m/s = ~200 km/h
    
    // تجاهل القراءات خارج السعودية
    if (!this.isInSaudiArabia(coords)) return false;
    
    // كشف GPS Spoofing
    if (this.detectSpoofing(coords)) return false;
    
    return true;
  }

  /**
   * Snap-to-Road: ربط الموقع بأقرب طريق
   */
  private async snapToRoad(coords: Coordinates): Promise<Coordinates> {
    try {
      const response = await fetch(
        `https://roads.googleapis.com/v1/snapToRoads?path=${coords.latitude},${coords.longitude}&interpolate=true&key=${API_KEY}`
      );
      const data = await response.json();
      
      if (data.snappedPoints?.length > 0) {
        const snapped = data.snappedPoints[0].location;
        return {
          ...coords,
          latitude: snapped.latitude,
          longitude: snapped.longitude,
          snappedToRoad: true,
        };
      }
    } catch (error) {
      console.warn('Snap-to-road failed, using raw GPS');
    }
    
    return coords;
  }

  /**
   * خوارزمية تقليل الإرسال الذكية
   * ترسل فقط عند:
   * - تغيير الموقع > 20 متر
   * - تغيير الاتجاه > 15 درجة
   * - مرور 10 ثوانٍ
   * - تغيير السرعة بشكل ملحوظ
   */
  private shouldSend(coords: Coordinates): boolean {
    if (!this.lastSentLocation) return true;
    
    const timeDiff = Date.now() - this.lastSentTime;
    const distanceDiff = haversineDistance(coords, this.lastSentLocation);
    const headingDiff = Math.abs(
      (coords.heading || 0) - (this.lastSentLocation.heading || 0)
    );
    
    // إرسال فوري إذا تحرك كثيراً
    if (distanceDiff > 50) return true;
    
    // إرسال عند تغيير الاتجاه (مهم للخرائط)
    if (headingDiff > 15 && distanceDiff > 10) return true;
    
    // إرسال دوري كل 10 ثوانٍ
    if (timeDiff > 10000) return true;
    
    // إرسال عند التوقف (سرعة = 0)
    if (coords.speed === 0 && this.lastSentLocation.speed !== 0) return true;
    
    // إرسال عند البدء بالحركة
    if (coords.speed && coords.speed > 0 && this.lastSentLocation.speed === 0) return true;
    
    return false;
  }

  /**
   * كشف GPS Spoofing (المواقع المزيفة)
   */
  private detectSpoofing(coords: Coordinates): boolean {
    // 1. دقة مثالية جداً (مشبوهة)
    if (coords.accuracy === 0) return true;
    
    // 2. سرعة غير منطقية
    if (this.lastSentLocation) {
      const timeDiff = (coords.timestamp - this.lastSentLocation.timestamp) / 1000;
      if (timeDiff > 0) {
        const distance = haversineDistance(coords, this.lastSentLocation);
        const calculatedSpeed = distance / timeDiff;
        if (calculatedSpeed > 100) return true; // > 360 km/h مستحيل
      }
    }
    
    // 3. Android: isFromMockProvider
    if (isAndroid() && (coords as any).isFromMockProvider) return true;
    
    return false;
  }

  /**
   * حفظ محلياً للعمل بدون إنترنت
   */
  private async saveLocally(coords: Coordinates, orderId: string) {
    const queue = await this.getLocalQueue(orderId);
    queue.push(coords);
    await this.setLocalQueue(orderId, queue);
    
    // محاولة إرسال المخزن عند عودة الإنترنت
    if (navigator.onLine && queue.length > 1) {
      await this.flushLocalQueue(orderId);
    }
  }
}
```

```typescript
@Injectable()
export class ETAPredictionService {
  /**
   * حساب ETA مع مراعاة عوامل متعددة
   */
  async predictETA(params: ETAPredictionParams): Promise<ETAPrediction> {
    const { from, to, scheduledTime, vehicleType, historicalData } = params;

    // 1. ETA الأساسي من Google (مع الزحام الحالي)
    const route = await this.routingService.calculateRoute({ from, to });
    const baseETA = route.recommended.durationInTraffic.minutes;

    // 2. تعديل حسب الوقت المجدول (الزحام المتوقع)
    const scheduledTrafficMultiplier = this.getTrafficMultiplier(scheduledTime);

    // 3. تعديل حسب نوع المركبة (الشاحنات أبطأ)
    const vehicleMultiplier = this.getVehicleMultiplier(vehicleType);

    // 4. تعديل حسب البيانات التاريخية
    const historicalMultiplier = historicalData
      ? this.getHistoricalMultiplier(historicalData, scheduledTime)
      : 1;

    // 5. تعديل حسب اليوم (الجمعة مختلف)
    const dayMultiplier = this.getDayMultiplier(scheduledTime);

    // 6. هامش أمان
    const safetyMargin = 1.15; // 15% هامش

    const predictedMinutes = Math.ceil(
      baseETA *
      scheduledTrafficMultiplier *
      vehicleMultiplier *
      historicalMultiplier *
      dayMultiplier *
      safetyMargin
    );

    // 7. نطاق الثقة (min-max)
    const confidence = this.calculateConfidence({
      baseETA,
      historicalData,
      trafficCondition: route.recommended.trafficCondition,
    });

    return {
      predictedMinutes,
      minMinutes: Math.ceil(predictedMinutes * 0.85),
      maxMinutes: Math.ceil(predictedMinutes * 1.25),
      confidence,
      factors: {
        baseETA,
        trafficMultiplier: scheduledTrafficMultiplier,
        vehicleMultiplier,
        historicalMultiplier,
        dayMultiplier,
      },
      trafficCondition: route.recommended.trafficCondition,
      distanceKm: route.recommended.distance.km,
      calculatedAt: new Date(),
    };
  }

  /**
   * مضاعف الزحام حسب الساعة
   */
  private getTrafficMultiplier(time: Date): number {
    const hour = time.getHours();
    const day = time.getDay();
    
    // ذروة الصباح (7-9 صباحاً)
    if (hour >= 7 && hour <= 9) return 1.4;
    
    // ذروة الظهر (12-2 ظهراً)
    if (hour >= 12 && hour <= 14) return 1.3;
    
    // ذروة المساء (5-8 مساءً)
    if (hour >= 17 && hour <= 20) return 1.5;
    
    // الليل (هادئ)
    if (hour >= 22 || hour <= 5) return 0.9;
    
    return 1.0;
  }

  /**
   * مضاعف نوع المركبة
   */
  private getVehicleMultiplier(type: string): number {
    const multipliers = {
      small: 1.0,
      medium: 1.1,
      large: 1.2,
      crane: 1.3,
    };
    return multipliers[type] || 1.0;
  }

  /**
   * مضاعف اليوم
   */
  private getDayMultiplier(time: Date): number {
    const day = time.getDay();
    // الجمعة (مختلف في السعودية)
    if (day === 5) return 0.85;
    // الخميس (ذروة نهاية الأسبوع)
    if (day === 4) return 1.2;
    // السبت (بداية الأسبوع)
    if (day === 6) return 1.1;
    return 1.0;
  }
```

### 11.2 Haversine Formula

```typescript
// utils/geo.ts
/**
 * حساب المسافة بين نقطتين على سطح الأرض
 * بدقة عالية باستخدام صيغة Haversine
 */
export function haversineDistance(
  point1: Coordinates,
  point2: Coordinates
): number {
  const R = 6371000; // نصف قطر الأرض بالمتر
  const toRad = (deg: number) => (deg * Math.PI) / 180;

  const dLat = toRad(point2.latitude - point1.latitude);
  const dLng = toRad(point2.longitude - point1.longitude);
  const lat1 = toRad(point1.latitude);
  const lat2 = toRad(point2.latitude);

  const a =
    Math.sin(dLat / 2) ** 2 +
    Math.sin(dLng / 2) ** 2 * Math.cos(lat1) * Math.cos(lat2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));

  return R * c; // المسافة بالمتر
}

/**
 * حساب نقطة وسطية بين عدة نقاط
 */
export function getCentroid(points: Coordinates[]): Coordinates {
  const lat = points.reduce((s, p) => s + p.latitude, 0) / points.length;
  const lng = points.reduce((s, p) => s + p.longitude, 0) / points.length;
  return { latitude: lat, longitude: lng, timestamp: Date.now() };
}

 * التحقق من أن الإحداثيات داخل السعودية
 */
export function isInSaudiArabia(coords: Coordinates): boolean {
  return (
    coords.latitude >= 16.3475 &&
    coords.latitude <= 32.1583 &&
    coords.longitude >= 34.6314 &&

  );
```

```typescript
      ...newReading,
      latitude: smoothedLat,
      longitude: smoothedLng,
      smoothed: true,
    };
  }

  /**
   * كشف القفزات المفاجئة (GPS Jumps)
   */
  detectJump(
    current: Coordinates,
    previous: Coordinates,
    timeDiffMs: number
  ): boolean {
    const distance = haversineDistance(current, previous);
    const timeDiffSec = timeDiffMs / 1000;
    const speed = distance / timeDiffSec; // m/s

    // إذا كانت السرعة > 100 م/ث (360 كم/س) = قفزة
    return speed > 100;
  }

  /**
   * معالجة فقدان الإشارة
   */
  handleSignalLoss(
    lastKnownLocation: Coordinates,
    lastKnownTime: number
  ): LocationEstimate {
    const timeSinceLast = Date.now() - lastKnownTime;

    if (timeSinceLast < 30000) {
      // أقل من 30 ثانية: استخدم آخر موقع
      return {
        location: lastKnownLocation,
        confidence: 0.9,
        source: 'last_known',
      };
    }

    if (timeSinceLast < 120000) {
      // أقل من دقيقتين: استنتج الموقع من السرعة والاتجاه
      const predicted = this.predictLocation(lastKnownLocation);
      return {
        location: predicted,
        confidence: 0.6,
        source: 'predicted',
      };
    }

    // أكثر من دقيقتين: الموقع غير موثوق
    return {
      location: lastKnownLocation,
      confidence: 0.2,
      source: 'stale',
      warning: 'Location may be outdated',
    };
  }

  /**
   * التنبؤ بالموقع بناءً على السرعة والاتجاه
   */
  private predictLocation(last: Coordinates): Coordinates {
    if (!last.speed || !last.heading) return last;

    const timeSinceSec = (Date.now() - last.timestamp) / 1000;
    const distanceMeters = last.speed * timeSinceSec;

    // حساب الإحداثيات الجديدة
    const R = 6371000;
    const lat1 = (last.latitude * Math.PI) / 180;
    const lng1 = (last.longitude * Math.PI) / 180;
    const bearing = (last.heading * Math.PI) / 180;
    const d = distanceMeters / R;

    const lat2 = Math.asin(
      Math.sin(lat1) * Math.cos(d) +
      Math.cos(lat1) * Math.sin(d) * Math.cos(bearing)
    );
    const lng2 =
      lng1 +
      Math.atan2(
        Math.sin(bearing) * Math.sin(d) * Math.cos(lat1),
        Math.cos(d) - Math.sin(lat1) * Math.sin(lat2)
      );

    return {
      latitude: (lat2 * 180) / Math.PI,
      longitude: (lng2 * 180) / Math.PI,
      timestamp: Date.now(),
      predicted: true,
    };
  }
}
```

### 12.2 Multi-Source Fusion

```typescript
/**
 * دمج مصادر متعددة للموقع للحصول على أفضل دقة
 * GPS + WiFi + Cell Towers + Sensors
 */
async getFusedLocation(): Promise<Coordinates> {
  const sources: LocationSource[] = [];

  // 1. GPS
  try {
    const gps = await this.getGPSLocation();
    sources.push({ ...gps, source: 'gps', weight: 1.0 });
  } catch {}

  // 2. WiFi (عبر Geolocation API)
  try {
    const wifi = await this.getWiFiLocation();
    sources.push({ ...wifi, source: 'wifi', weight: 0.7 });
  } catch {}

  // 3. Cell Towers
  try {
    const cell = await this.getCellLocation();
    sources.push({ ...cell, source: 'cell', weight: 0.4 });
  } catch {}

  // 4. دمج باستخدام Weighted Average
  return this.weightedAverage(sources);
}

private weightedAverage(sources: LocationSource[]): Coordinates {
  const totalWeight = sources.reduce((s, src) => s + src.weight, 0);
  
  const lat = sources.reduce((s, src) => s + src.latitude * src.weight, 0) / totalWeight;
  const lng = sources.reduce((s, src) => s + src.longitude * src.weight, 0) / totalWeight;
  const accuracy = Math.min(...sources.map(s => s.accuracy || 999));

  return {
    latitude: lat,
    longitude: lng,
    accuracy,
    timestamp: Date.now(),
    fused: true,
    sources: sources.map(s => s.source),
  };
}
```

```typescript
class OfflineLocationQueue {
  private db: IDBDatabase;

  async saveLocation(coords: Coordinates, orderId: string) {
    const tx = this.db.transaction('locations', 'readwrite');
    const store = tx.objectStore('locations');
    await store.add({
      orderId,
      coordinates: coords,
      savedAt: Date.now(),
      synced: false,
    });
  }

  async flushPending() {
    if (!navigator.onLine) return;

    const tx = this.db.transaction('locations', 'readwrite');
    const store = tx.objectStore('locations');
    const pending = await store.getAll();
    const unsynced = pending.filter(p => !p.synced);

    // إرسال على دفعات
    const batches = chunk(unsynced, 50);
    for (const batch of batches) {
      try {
        await api.post('/tracking/batch', { locations: batch });
        for (const item of batch) {
          item.synced = true;
          await store.put(item);
        }
      } catch (error) {
        console.error('Sync failed, will retry', error);
        break;
      }
    }
  }
}
```

### 19.2 Anti-Spoofing

```typescript
// كشف المواقع المزيفة
class AntiSpoofingService {
  detect(coords: Coordinates, deviceInfo: DeviceInfo): SpoofingRisk {
    const risks: string[] = [];
    let score = 0;

    // 1. Mock Provider (Android)
    if (deviceInfo.isMockProvider) {
      risks.push('mock_provider');
      score += 50;
    }

    // 2. Jailbreak/Root detection
    if (deviceInfo.isJailbroken || deviceInfo.isRooted) {
      risks.push('jailbroken_device');
      score += 30;
    }

    // 3. GPS Spoofing apps
    if (this.hasSpoofingApp(deviceInfo.installedApps)) {
      risks.push('spoofing_app_detected');
      score += 40;
    }

    // 4. سرعة غير منطقية
    if (this.detectImpossibleSpeed(coords)) {
      risks.push('impossible_speed');
      score += 30;
    }

    // 5. teleportation (قفزات مكانية)
    if (this.detectTeleportation(coords)) {
      risks.push('teleportation');
      score += 40;
    }

    // 6. دقة مثالية جداً (مشبوهة)
    if (coords.accuracy === 0 || coords.accuracy < 1) {
      risks.push('suspicious_accuracy');
      score += 20;
    }

    return {
      isSpoofed: score >= 50,
      riskScore: score,
      risks,
      action: score >= 50 ? 'reject' : score >= 30 ? 'flag' : 'accept',
    };
  }
}
```
