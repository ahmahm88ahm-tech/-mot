# إعداد خدمة الويب على Replit

هذا التوثيق يصف إنشاء Web artifact منفصل — **لا يلمس** `.replit` الخاص بالـ Backend الحيّ.

## الخطوات
1. أنشئ Repl جديد من قالب **Node.js** (أو أضف خدمة Web داخل نفس المشروع إن دعمت المنصّة خدمات متعدّدة).
2. اجعل جذر الخدمة = `apps/web`.
3. متغيرات البيئة (في Secrets):
   - `NEXT_PUBLIC_API_URL` = رابط الـ Backend artifact (بدون `/` في النهاية).
4. أمر التثبيت: `npm install`
5. أمر التشغيل: `npm run dev`  (المنصّة تضبط `PORT` تلقائياً).
6. انتظر الرابط، ثم افتحه — يجب أن ترى المشهد السينمائي.

## ملاحظات
- الـ Backend يجب أن يكون صاحياً (تبويب مفتوح أو ping) حتى يعمل login/dashboard.
- إن ظهرت صفحة بيضاء: تأكّد أن `NEXT_PUBLIC_API_URL` مضبوط وأن الـ Backend يردّ على `/api/v1/health`.
