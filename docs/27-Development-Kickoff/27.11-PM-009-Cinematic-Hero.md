# PM-009 — إعادة بناء الـ Hero: من بروشور إلى مشهد سينمائي

**Document ID:** MQ-PM-009  
**الإصدار:** 1.0.0  
**التاريخ:** 25 يوليو 2026  
**الحالة:** مُنفَّذ  
**المشروع:** MOTANAQIL (مُتنقِّل)

---

## 🎯 القرار

استبدال الـ Hero القديم (بطاقة سوداء على خلفية سوداء = بروشور ميت) بمشهد سينمائي بعرض كامل يحكي قصة الشركة بصرياً دون كلمة إضافية.

---

## 🔍 المشكلة

اللقطة السابقة أظهرت:
- بطاقة سوداء كبيرة على خلفية سوداء → **تأثير البروشور الميت**
- لا حركة، لا حياة، لا إحساس بأن الشركة تعمل فعلاً
- الهوية البصرية مخبأة داخل لوحة ثابتة لا تُعبّر عن خدمة نقل حقيقية

## 🏗️ المعمارية البصرية

```
<section.scene>                    ← الحاوية (92vh، parallax بالماوس)
  ├── <svg.scene-svg>              ← مشهد SVG: سماء شروق، فيلا، نخيل
  │   ├── سماء (تدرج لوني دافئ)
  │   ├── شمس نابضة (sunPulse animation)
  │   ├── غيوم تنجرف (drift animation)
  │   ├── نخيل يتمايل (sway animation)
  │   ├── فيلا سعودية حديثة (نوافذ مضيئة)
  │   ├── فريق عمل + صناديق (إحساس العمل الفعلي)
  │   └── طريق + خط ذهبي متقطع
  ├── <div.trucks.scene-fg>        ← شاحنات HTML متحركة (z-index: 2)
  │   ├── .truck.t3  (أبعد — أصغر — أبطأ)
  │   ├── .truck.t2  (وسط)
  │   └── .truck.t1  (أقرب — أكبر — أسرع)
  └── <div.glass>                  ← بطاقة زجاجية (backdrop-filter: blur)
      ├── badge: مسجلة 2018
      ├── h1: نقل الأثاث وتركيبه باحترافية وأمان
      ├── p: وصف مختصر
      ├── CTAs: اطلب عرض السعر + تعرّف على خدماتنا
      └── trust-glass: 3 نقاط ثقة
```

## 🎬 الرسوم المتحركة المُستخدَمة

| العنصر | الـ Animation | المدة | الملاحظة |
|--------|--------------|-------|---------|
| الشاحنة الكبيرة (t1) | truckMove1 | 17s linear | تعبر من اليمين لليسار |
| الشاحنة المتوسطة (t2) | truckMove2 | 23s linear | delay: -6s |
| الشاحنة البعيدة (t3) | truckMove3 | 30s linear | delay: -14s، opacity: 0.6 |
| عجلات الشاحنات | wheelSpin | 1.1s linear | تدور باستمرار |
| النخيل (قريب) | sway | 5.5s ease-in-out | تمايل -1.6° → +1.6° |
| النخيل (بعيد) | sway2 | 7s ease-in-out | delay: -2s |
| الغيوم | drift | 60s / 90s linear | تنجرف أفقياً |
| الشمس (هالة) | sunPulse | 4.5s ease-in-out | تنبض scale(1) → scale(1.12) |
| البطاقة الزجاجية | glassShine | 7s | وميض ضوء أفقي |
| Parallax الماوس | CSS vars (--mx, --my) | 0.25s ease-out | طبقتان بعمق مختلف |
| مؤشر التمرير | scrollBob | 1.6s ease-in-out | يرتد للأسفل |

## 🔑 مفتاح الصورة الحقيقية

```typescript
// في cinematic-hero.tsx السطر 13
const SCENE_PHOTO: string | null = null;
// غيّره إلى:
const SCENE_PHOTO: string | null = '/images/hero-scene.jpg';
```

**النتيجة:** الصورة تحلّ محل طبقة SVG السماء مع بقاء الشاحنات المتحركة فوقها — أفضل العالمين.

**مواضع الصور المدعومة:**
- `apps/web/public/images/hero-scene.jpg` → خلفية المشهد الرئيسي
- `apps/web/public/images/team-real.jpg` → الـ id-visual في قسم الهوية
