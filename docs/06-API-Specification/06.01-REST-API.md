## 1. المعايير العامة

### 1.1 البروتوكول
- **HTTPS** فقط (TLS 1.3)
- **Content-Type:** `application/json`
- **Accept-Language:** `ar`, `en`
- **Charset:** UTF-8

### 1.2 Headers المطلوبة

```http
Authorization: Bearer <token>
Content-Type: application/json
Accept: application/json
Accept-Language: ar
X-Request-ID: <uuid>
X-Client-Version: 1.0.0
```

### 1.2 Response Format

#### نجاح (Success)
```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "name": "value"
  },
  "meta": {
    "timestamp": "2026-07-23T10:30:00Z",
    "requestId": "uuid"
  }
}
```

#### قائمة (List)
```json
{
  "success": true,
  "data": [...],
  "meta": {
    "page": 1,
    "limit": 20,
    "total": 150,
    "totalPages": 8,
    "hasNext": true,
    "hasPrev": false
  }
}
```

#### خطأ (Error)
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid input data",
    "details": [
      {
        "field": "email",
        "message": "Invalid email format",
        "value": "invalid-email"
      }
    ]
  },
  "meta": {
    "timestamp": "2026-07-23T10:30:00Z",
    "requestId": "uuid"
  }
}
```

### 1.3 HTTP Status Codes

| الكود | المعنى | الاستخدام |
|------|--------|----------|
| **200** | OK | نجاح GET, PUT, PATCH |
| **201** | Created | نجاح POST |
| **204** | No Content | نجاح DELETE |
| **400** | Bad Request | خطأ في المدخلات |
| **401** | Unauthorized | غير مصدق |
| **403** | Forbidden | لا صلاحية |
| **404** | Not Found | المورد غير موجود |
| **409** | Conflict | تعارض (مثل email موجود) |
| **422** | Unprocessable | خطأ في التحقق |
| **429** | Too Many Requests | تجاوز الحد |
| **500** | Internal Server Error | خطأ داخلي |
| **503** | Service Unavailable | الخدمة غير متاحة |

## 2. المصادقة والأمان

### 2.1 JWT Authentication

```typescript
// Login Response
{
  "success": true,
  "data": {
    "user": {
      "id": "uuid",
      "email": "user@example.com",
      "role": "customer",
      "firstName": "أحمد",
      "lastName": "محمد"
    },
    "accessToken": "eyJhbGciOiJIUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 604800
  }
}
```

### 2.2 Token Lifecycle
- **Access Token:** 7 أيام
- **Refresh Token:** 30 يوم
- **Rotation:** Refresh token يتجدد مع كل استخدام

### 2.3 Security Headers

```http
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
X-XSS-Protection: 1; mode=block
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'
```

## 3. إدارة الأخطاء

### 3.1 Error Codes

| الكود | المعنى |
|------|--------|
| `AUTHENTICATION_ERROR` | فشل المصادقة |
| `AUTHORIZATION_ERROR` | لا صلاحية |
| `VALIDATION_ERROR` | خطأ في المدخلات |
| `NOT_FOUND_ERROR` | المورد غير موجود |
| `CONFLICT_ERROR` | تعارض في البيانات |
| `RATE_LIMIT_ERROR` | تجاوز الحد |
| `INTERNAL_ERROR` | خطأ داخلي |
| `SERVICE_UNAVAILABLE` | الخدمة غير متاحة |
| `ORDER_INVALID_TRANSITION` | انتقال حالة غير صالح |
| `PAYMENT_REQUIRED` | الدفع مطلوب |

### 3.2 أمثلة الأخطاء

#### Validation Error
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Validation failed",
    "details": [
      {
        "field": "phone",

      },
      {
        "field": "from_latitude",
        "message": "Latitude is required",
        "value": null
      }
    ]
  }
}
```

#### Not Found Error
```json
{
  "success": false,
  "error": {
    "code": "NOT_FOUND_ERROR",
    "message": "Order not found",
    "details": {
      "resource": "order",
```

## 5. Endpoints المصادقة

### 5.1 تسجيل جديد
```http
POST /auth/register
```

**Request Body:**
```json
{
  "firstName": "أحمد",
  "lastName": "محمد",
  "email": "ahmed@example.com",
  "phone": "+966580144416",
  "password": "SecurePass123!",
  "confirmPassword": "SecurePass123!",
  "cityId": "uuid",
  "districtId": "uuid"
}
```

**Response (201):**
```json
{
  "success": true,
  "data": {
    "user": {
      "id": "uuid",
      "firstName": "أحمد",
      "lastName": "محمد",
      "email": "ahmed@example.com",
      "phone": "+966580144416",
      "role": "customer",
      "status": "active",
      "createdAt": "2026-07-23T10:30:00Z"
    },
    "accessToken": "eyJ...",
    "refreshToken": "eyJ...",
    "expiresIn": 604800
  }
}
```

**Validation Rules:**
- `firstName`: مطلوب، 2-50 حرف
- `lastName`: مطلوب، 2-50 حرف
- `email`: مطلوب، صيغة بريد صحيحة، فريد
- `phone`: مطلوب، صيغة سعودية، فريد
- `password`: مطلوب، 8+ أحرف، حرف كبير، رقم، رمز خاص

## 6. Endpoints المستخدمين

### 6.1 قائمة المستخدمين (Admin)
```http
GET /users
Authorization: Bearer <token>
Roles: admin, manager
```

**Query Parameters:**
- `page`: رقم الصفحة (default: 1)
- `limit`: عدد العناصر (default: 20, max: 100)
- `search`: بحث بالاسم أو البريد أو الهاتف
- `role`: تصفية بالدور
- `status`: تصفية بالحالة
- `sortBy`: الترتيب (default: createdAt)
- `sortOrder`: asc أو desc

**Response (200):**
```json
{
  "success": true,
```

### 7.7 تحديث حالة الطلب (Admin/Employee)
```http
PATCH /orders/:id/status
Authorization: Bearer <token>
Roles: admin, manager, employee, driver
```

**Request Body:**
```json
{
  "status": "driver_started",
  "reason": "بدأت الحركة",
  "location": {
    "latitude": 24.774265,
    "longitude": 46.738586
  }
}
```

**Response (200):**
```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "status": "driver_started",
    "updatedAt": "2026-07-23T11:15:00Z"
  }
}
```

**Valid Transitions:**
- `created` → `confirmed`, `cancelled`
- `confirmed` → `assigned`, `cancelled`
- `assigned` → `driver_started`, `cancelled`
- `driver_started` → `arrived`, `cancelled`
- `arrived` → `loading`, `cancelled`
- `loading` → `moving`, `cancelled`
- `moving` → `unloading`, `cancelled`
- `unloading` → `installation`, `completed`, `cancelled`
- `installation` → `completed`, `cancelled`

### 19.1 Limits

| Endpoint | Limit | Window |

| **Public** | 100 requests | 15 minutes |
| **Authenticated** | 500 requests | 15 minutes |

## 20. Pagination & Filtering

### 20.1 Pagination Parameters
- `page`: رقم الصفحة (default: 1, min: 1)
- `limit`: عدد العناصر (default: 20, min: 1, max: 100)

### 20.2 Sorting Parameters
- `sortBy`: الحقل للترتيب (default: createdAt)
- `sortOrder`: `asc` أو `desc` (default: desc)

### 20.3 Filtering Parameters
- `search`: بحث نصي عام
- `status`: تصفية بالحالة
- `dateFrom`, `dateTo`: نطاق تاريخي (ISO 8601)
- `cityId`, `branchId`: تصفية جغرافية

### 20.4 Response Meta
```json
{
  "meta": {
    "page": 1,
    "limit": 20,
    "total": 150,
    "totalPages": 8,
    "hasNext": true,
    "hasPrev": false
  }
}
```
