## 1. الكيانات الأساسية (Core Entities)

### 1.1 User (المستخدم)

```typescript
interface User {
  id: UUID;
  personalInfo: PersonalInfo;
  contactInfo: ContactInfo;
  address: Address;
  credentials: Credentials;
  role: UserRole;
  status: UserStatus;
  preferences: UserPreferences;
  metadata: Metadata;
}

interface PersonalInfo {
  firstName: string;
  lastName: string;
  nationalId?: string;
  dateOfBirth?: Date;
  gender?: 'male' | 'female';
}

interface ContactInfo {
  email: string;
  emailVerified: boolean;
  phone: string;
  phoneVerified: boolean;
  whatsapp?: string;
}

interface Address {
  line1?: string;
  line2?: string;
  district?: District;
  city?: City;
  region?: Region;
  postalCode?: string;
  coordinates?: Coordinates;
}

interface Credentials {
  passwordHash: string;
  twoFactorEnabled: boolean;
  lastPasswordChange: Date;
}

type UserRole = 'customer' | 'employee' | 'driver' | 'admin' | 'manager' | 'super_admin';
type UserStatus = 'active' | 'inactive' | 'suspended' | 'deleted';
```

**المسؤوليات:**
- إدارة الهوية والمصادقة
- تخزين معلومات الاتصال
- ربط الطلبات والمراجعات

**العلاقات:**
- One-to-Many: Orders (كعميل)
- One-to-Many: Orders (كموظف منفذ)
- One-to-Many: Reviews
- Many-to-Many: Roles

### 1.2 Order (الطلب)

interface Order {
  id: UUID;
  orderNumber: string;
  customer: User;
  service: Service;
  branch?: Branch;
  
  locations: OrderLocations;
  pricing: OrderPricing;
  scheduling: OrderScheduling;

  paymentStatus: PaymentStatus;

  timestamps: OrderTimestamps;
}

  from: LocationDetails;

  address: string;
  district?: District;
  city?: City;
  coordinates: Coordinates;

  notes?: string;
}

  distanceKm: number;

  basePrice: number;
  distancePrice: number;
  extraServicesPrice: number;
  discountAmount: number;
  taxAmount: number;
  totalAmount: number;
  currency: string;
}

interface OrderScheduling {
  scheduledDate?: Date;
  scheduledSlot?: 'morning' | 'afternoon' | 'evening';
}

interface OrderExecution {
  assignedTo?: User;
  teamSize: number;
  vehicleType?: VehicleType;
  vehiclePlate?: string;
}

type OrderStatus = 
  | 'created'
  | 'confirmed'
  | 'assigned'
  | 'driver_started'
  | 'arrived'
  | 'loading'
  | 'moving'
  | 'unloading'
  | 'installation'
  | 'completed'
  | 'cancelled'
  | 'refunded';

type OrderPriority = 'low' | 'normal' | 'high' | 'urgent';
type PaymentStatus = 'pending' | 'paid' | 'partial' | 'refunded';

## 6. Invariants (الثوابت)

### 6.1 Order Invariants
- الطلب يجب أن يكون له عميل صالح
- الموقع من وإلى مطلوبان
- السعر الإجمالي يجب أن يكون >= 0
- لا يمكن الانتقال من `completed` إلى حالة أخرى
- لا يمكن إلغاء طلب بعد `moving`

### 6.2 User Invariants
- البريد الإلكتروني فريد
- رقم الهاتف فريد
- كلمة المرور مشفرة دائماً
- المستخدم المحذوف لا يمكن تسجيل دخوله

### 6.3 Service Invariants
- اسم الخدمة مطلوب
- السعر الأساسي >= 0
- الـ slug فريد
