# PM-003 — Minimum Buildable Product (MBP)

**الإصدار:** v3.4.0  
**التاريخ:** 2026-07-24  
**الحالة:** مُنفَّذ — الكود في `apps/`

---

## القرار

تسليم أول مشروع حقيقي قابل للبناء والتشغيل بدلاً من كود مبعثر عبر الردود.

**النطاق (MBP):** مصادقة + طلبات + صحة + قاعدة بيانات مزروعة + واجهتان.

---

## القرارات البراغماتية (ADR-0007)

1. **لا monorepo workspaces معقّد** — كل تطبيق مكتفٍ بذاته (`npm install` داخل مجلده).
2. **الحد الأدنى الوظيفي فقط الآن**: لا MFA، لا state-machine معقّدة، لا notifications، لا Tailwind — كلها حزم لاحقة.
3. DTOs مسطّحة (بلا كائنات متداخلة) لتفادي اعتماديات هشة.

---

## هيكل التطبيقات

```
apps/
├── api/          ← NestJS + Prisma + PostgreSQL (منفذ 4000)
├── web/          ← Next.js 14 — واجهة العميل (منفذ 3000)
└── admin/        ← Next.js 14 — لوحة الإدارة scaffold (منفذ 3001)
```

---

## ترتيب البناء على Replit

```bash
# 1. Backend أولاً
cd apps/api
npm install
npx prisma generate
npx prisma db push        # أسرع من migrate على Replit
npm run prisma:seed       # يزرع: admin + customer + driver + مدينة + خدمات
npm run start:dev         # يقلع على :4000

# 2. تحقق
curl <URL>/api/v1/health                       # → {"ok":true}
curl -X POST <URL>/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"identifier":"customer@motanaqil.com","password":"Motanaqil@2026"}'

# 3. Web (بعد نجاح Backend)
cd apps/web && npm install && npm run dev      # منفذ 3000

# 4. Admin
cd apps/admin && npm install && npm run dev   # منفذ 3001
```
