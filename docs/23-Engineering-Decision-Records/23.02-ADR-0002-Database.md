# ADR-0002: اختيار قاعدة البيانات (PostgreSQL + Prisma)

**Status:** ✅ Accepted  
**Date:** 2026-07-23  
**Deciders:** فريق Buytuk (Tech Lead, Backend Lead)  
**Consulted:** DevOps Lead, Product Owner  
**Informed:** فريق التطوير

---

## Context

مشروع MOTANAQIL يحتاج قاعدة بيانات تدعم:

- **بيانات علائقية معقدة** — Orders, Users, Services, Cities, Districts
- **بيانات جغرافية** — Locations, Geofencing, Routes (PostGIS)
- **JSON/NoSQL** — Settings, Metadata, Audit Logs
- **Full-text Search** — البحث في الخدمات والمدن
- **Transactions** — ACID للطلبات والمدفوعات
- **Scalability** — Read Replicas, Partitioning

**المشكلة:** اختيار قاعدة بيانات و ORM توازن بين:
- الأداء (Performance)
- المرونة (Flexibility)
- سهولة التطوير (Developer Experience)
- التكلفة (Cost)

## Decision Drivers

1. **بيانات جغرافية** — نحتاج PostGIS للخرائط والـ Geofencing
2. **ACID** — الطلبات والمدفوعات تحتاج Transactions قوية
3. **JSON Support** — Settings, Metadata تحتاج مرونة
4. **Developer Experience** — ORM قوي يقلل وقت التطوير
5. **Scalability** — Read Replicas, Partitioning للنمو

## Considered Options

### Option 1: PostgreSQL + Prisma ✅

**الوصف:** قاعدة بيانات علائقية قوية مع ORM حديث.

**المزايا:**
- ✅ **PostGIS** — دعم جغرافي ممتاز (الخرائط، Geofencing)
- ✅ **JSONB** — دعم JSON كامل (Settings, Metadata)
- ✅ **Full-text Search** — بحث نصي مدمج
- ✅ **ACID** — Transactions قوية
- ✅ **Read Replicas** — Scaling للقراءة
- ✅ **Partitioning** — للجداول الكبيرة (Orders, Audit Logs)
- ✅ **Prisma** — Type-safe ORM، migrations سهلة، Developer Experience ممتاز
- ✅ **مجاني** — Open Source، لا تكلفة ترخيص

**العيوب:**
- ❌ **تعقيد** — PostgreSQL معقد في الإدارة (لكن Managed Services تعوض)
- ❌ **Scaling كتابة** — محدود (لكن Read Replicas + Partitioning يعوضان)

### Option 2: MongoDB + Mongoose

**الوصف:** قاعدة بيانات NoSQL document-based.

**المزايا:**
- ✅ **مرونة** — Schema-less، سريع التطوير
- ✅ **Scaling** — Sharding سهل
- ✅ **JSON Native** — مناسب للبيانات غير المهيكلة

**العيوب:**
- ❌ **لا PostGIS** — دعم جغرافي ضعيف (GeoJSON محدود)
- ❌ **لا ACID كامل** — Transactions محدودة
- ❌ **لا Joins** — صعب للعلاقات المعقدة (Orders ↔ Users ↔ Services)
- ❌ **Mongoose** — ORM قديم، Type-safety ضعيف

### Option 3: MySQL + TypeORM

**الوصف:** قاعدة بيانات علائقية شائعة مع ORM تقليدي.

**المزايا:**
- ✅ **شائع** — معرفة واسعة في السوق
- ✅ **أداء** — سريع للقراءة
- ✅ **مجاني** — Open Source

**العيوب:**
- ❌ **PostGIS محدود** — MySQL Spatial أقل قوة من PostgreSQL
- ❌ **JSON ضعيف** — MySQL JSON أقل مرونة من PostgreSQL JSONB
- ❌ **TypeORM** — ORM قديم، bugs كثيرة، Developer Experience سيء
- ❌ **Full-text Search** — محدود مقارنة بـ PostgreSQL

## Decision Outcome

**Chosen option:** Option 1 — PostgreSQL + Prisma

**السبب:**
1. **PostGIS** — ضروري للخرائط والـ Geofencing (ملف 21-Maps)
2. **JSONB** — ضروري لـ Settings, Metadata, Audit Logs
3. **ACID** — ضروري للطلبات والمدفوعات
4. **Prisma** — Developer Experience ممتاز، Type-safe، migrations سهلة
5. **Full-text Search** — ضروري لـ SEO والبحث في الخدمات
6. **Read Replicas + Partitioning** — للنمو المستقبلي

**البنية المختارة:**
```
Database: PostgreSQL 15+
Extension: PostGIS (للبيانات الجغرافية)
ORM: Prisma 5+
Hosting: AWS RDS (Multi-AZ, Read Replicas)
Backup: Automated Daily + PITR
```

## Consequences

### إيجابية
- ✅ **بيانات جغرافية قوية** — PostGIS يدعم Geofencing, Routes, Spatial Queries
- ✅ **مرونة JSON** — JSONB لـ Settings, Metadata بدون Schema ثابت
- ✅ **ACID كامل** — Transactions قوية للطلبات والمدفوعات
- ✅ **Developer Experience** — Prisma Type-safe، migrations سهلة، IntelliSense
- ✅ **Full-text Search** — بحث نصي مدمج للخدمات والمدن
- ✅ **Scalability** — Read Replicas, Partitioning للنمو

### سلبية
- ⚠️ **تعقيد الإدارة** — PostgreSQL معقد (لكن AWS RDS Managed يعوض)
- ⚠️ **Scaling كتابة محدود** — لا Sharding (لكن Partitioning + Read Replicas يعوضان)

### مخاطر
- 🔴 **Risk:** PostGIS معقد في الاستعلامات  
  **Mitigation:** توثيق استعلامات PostGIS + Training للفريق
- 🔴 **Risk:** Prisma Performance في Queries معقدة  
  **Mitigation:** Raw Queries للـ complex queries + Performance Monitoring

## Compliance

- ✅ **Migrations:** كل تغيير في Schema يمر عبر Prisma Migrate
- ✅ **Code Review:** 2 reviewers للـ migrations الحرجة
- ✅ **Tests:** Integration tests لكل Query معقد
- ✅ **Monitoring:** Performance Insights + Slow Queries Alerts
