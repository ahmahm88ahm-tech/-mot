# PM-005 — إعادة بناء الواجهة: Design System حقيقي

**الإصدار:** v1.4.0
**التاريخ:** 2026-07-24
**الحالة:** مدمج في المصدر

## نطاق القرار

إعادة بناء `apps/web` من الصفر بـ Design System مخصص (لا Tailwind) مع هوية بصرية محددة.
CSS مخصص يُبنى بنفس build config الحالي دون تغيير.

## الملفات المُضافة

| الملف | الوصف |
|---|---|
| `apps/web/src/app/globals.css` | Design System كامل: tokens، أزرار، بطاقات، حقول، Bento، حركة |
| `apps/web/src/app/layout.tsx` | Root layout مع خلفية طبقاتية حية |
| `apps/web/src/lib/useInView.ts` | Hooks: `useInView` و`useCountUp` |
| `apps/web/src/lib/api.ts` | `apiFetch` موحّد مع JWT من `localStorage` |
| `apps/web/src/app/page.tsx` | الصفحة الرئيسية: split افتتاحي + شريط مدن + Bento خدمات + عدادات حية + CTA |
| `apps/web/src/app/login/page.tsx` | صفحة الدخول: split بصري + نموذج متصل بـ `/auth/login` |
| `apps/web/src/app/dashboard/page.tsx` | لوحة التحكم: Bento حي + قائمة الطلبات من `/orders` |

## قرارات تقنية

- **CSS مخصص لا Tailwind:** لا تغيير في build config، لا خطر كسر build قائم.
- **`apiFetch`:** يقرأ `NEXT_PUBLIC_API_URL` (افتراضي `http://localhost:4000`)، يُرفق JWT تلقائياً.
- **`useInView`:** يستخدم `IntersectionObserver` مع `disconnect()` بعد أول ظهور.
- **`useCountUp`:** `requestAnimationFrame` مع easing cubic.

## عناصر مستبعدة من الدمج

- صفحة HTML المقارنة (قبل/بعد) — توضيحية فقط.
- النصوص الخطابية وأوامر التشغيل وطلبات الإيصال.
