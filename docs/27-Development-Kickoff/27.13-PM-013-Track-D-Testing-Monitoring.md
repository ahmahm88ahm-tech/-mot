## السيناريو الذهبي (E2E)

```
صحة API ✓ → تحميل الصفحة الرئيسية ✓ → تسجيل دخول ✓
→ إنشاء طلب (MTQ-XXXX) ✓ → ظهوره في اللوحة ✓
→ فاتورة ضريبية مبسّطة + QR ✓ → «الدفع بعد إتمام الخدمة» ✓
→ صفحة الضمان ✓ → سياسة الخصوصية ✓ → الشروط ✓
```

## ما تغيّر وما لم يتغيّر

**تغيّر (إضافات):**
- وحدة مراقبة: 3 ملفات API (metrics service + controller + module)
- صفحة حالة داخلية: `/status` في Next.js
- اختبارات E2E: 3 ملفات (playwright config + fixtures + smoke spec)
- قائمة إطلاق: `GO-LIVE-CHECKLIST.md`
- تعديل مضاف في `app.module.ts` (سطران)

**لم يتغيّر:**
- auth / orders / invoices / health
- المشهد السينمائي والهوية البصرية
- الفاتورة الزكوية
- schema قاعدة البيانات

**صفر مساس بالسلوك العامل.**
