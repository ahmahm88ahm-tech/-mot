## 1. نظرة عامة ومبادئ النشر

### 1.1 مبادئ النشر

| المبدأ | التطبيق |
|--------|--------|
| **Infrastructure as Code (IaC)** | كل البنية معرّفة في Terraform، لا نقرّ على واجهات |
| **Immutable Infrastructure** | لا نعدّل خوادم حية، نبني صوراً جديدة ونستبدل |
| **Reproducible Builds** | نفس الكود → نفس الصورة دائماً (deterministic) |
| **Automated Pipelines** | النشر عبر CI/CD فقط، لا نشر يدوي للإنتاج |
| **Zero Downtime** | استراتيجيات Blue-Green / Rolling / Canary |
| **Configuration as Code** | الإعدادات في Git (مشفرّة)، لا في الخوادم |
| **Separation of Environments** | عزل كامل بين dev/staging/prod |
| **Observability First** | لا نشر بدون monitoring/logging جاهز |
| **Rollback Ready** | كل نشر قابل للتراجع فوراً |

### 1.2 نطاق الدليل


## 5. Docker & Containerization

### 5.1 Dockerfile للـ API (NestJS) — Multi-Stage محصّن

```dockerfile
# ============================================
# Stage 1: Dependencies
# ============================================
FROM node:20.10-alpine3.18 AS deps
WORKDIR /app

# أدوات build لـ native modules (bcrypt, sharp)
RUN apk add --no-cache python3 make g++ libc6-compat

# نسخ ملفات التعريف فقط (لطبقة كاش فعّالة)
COPY apps/api/package*.json ./
COPY package*.json ./

# تثبيت الإنتاج + التطوير للبناء
RUN npm ci --ignore-scripts=false

# ============================================
# Stage 2: Build
# ============================================
FROM node:20.10-alpine3.18 AS builder
WORKDIR /app

COPY --from=deps /app/node_modules ./node_modules
COPY apps/api/ ./apps/api/
COPY packages/ ./packages/
COPY prisma/ ./prisma/
COPY tsconfig*.json ./

# توليد Prisma Client
RUN npx prisma generate

# بناء التطبيق
RUN npm run build:api

# تثبيت إنتاج فقط (صورة أنحف)
RUN npm ci --only=production --ignore-scripts && npm cache clean --force

# ============================================
# Stage 3: Runtime (محصّن)
# ============================================
FROM node:20.10-alpine3.18 AS runner
WORKDIR /app

# أمان: تحديثات + مستخدم غير root + أدوات ضرورية فقط
RUN apk add --no-cache tini curl ca-certificates \
    && addgroup -g 1001 -S appgroup \
    && adduser -S appuser -u 1001 -G appgroup

# نسخ المخرجات
COPY --from=builder --chown=appuser:appgroup /app/dist ./dist
COPY --from=builder --chown=appuser:appgroup /app/node_modules ./node_modules
COPY --from=builder --chown=appuser:appgroup /app/prisma ./prisma
COPY --from=builder --chown=appuser:appgroup /app/package.json ./package.json

# متغيرات بيئة آمنة افتراضياً
ENV NODE_ENV=production \
    NODE_OPTIONS="--max-old-space-size=1024" \
    PORT=4000

# لا root
USER appuser

EXPOSE 4000

# Health check
HEALTHCHECK --interval=30s --timeout=5s --start-period=40s --retries=3 \
  CMD curl -f http://localhost:4000/health || exit 1

# tini لمعالجة الإشارات (SIGTERM) بشكل صحيح
ENTRYPOINT ["/sbin/tini", "--"]
CMD ["node", "dist/main.js"]
```

### 5.2 Dockerfile للـ Web (Next.js) — Standalone محسّن

```dockerfile
# ============================================
# Stage 1: Deps
# ============================================
FROM node:20.10-alpine3.18 AS deps
WORKDIR /app
RUN apk add --no-cache libc6-compat
COPY apps/web/package*.json ./
RUN npm ci

# ============================================
# Stage 2: Build
# ============================================
FROM node:20.10-alpine3.18 AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY apps/web/ ./apps/web/
COPY packages/ ./packages/

# متغيرات بناء عامة (آمنة للـ client)
ARG NEXT_PUBLIC_API_URL
ARG NEXT_PUBLIC_GOOGLE_MAPS_KEY
ENV NEXT_PUBLIC_API_URL=$NEXT_PUBLIC_API_URL
ENV NEXT_PUBLIC_GOOGLE_MAPS_KEY=$NEXT_PUBLIC_GOOGLE_MAPS_KEY

ENV NEXT_TELEMETRY_DISABLED=1
RUN npm run build:web

# ============================================
# Stage 3: Runtime
# ============================================
FROM node:20.10-alpine3.18 AS runner
WORKDIR /app
ENV NODE_ENV=production
ENV NEXT_TELEMETRY_DISABLED=1
ENV PORT=3000
ENV HOSTNAME="0.0.0.0"

RUN addgroup -g 1001 -S appgroup && adduser -S appuser -u 1001 -G appgroup

# Next.js standalone output (صورة أنحف بكثير)
COPY --from=builder --chown=appuser:appgroup /app/apps/web/public ./apps/web/public
COPY --from=builder --chown=appuser:appgroup /app/apps/web/.next/standalone ./
COPY --from=builder --chown=appuser:appgroup /app/apps/web/.next/static ./apps/web/.next/static

USER appuser
EXPOSE 3000

HEALTHCHECK --interval=30s --timeout=5s --start-period=30s --retries=3 \
  CMD wget -qO- http://localhost:3000/api/health || exit 1

CMD ["node", "apps/web/server.js"]
```

```bash
# وسم الصور بمعيار semver + commit SHA (للتتبع)
VERSION=$(git describe --tags --always)
COMMIT=$(git rev-parse --short HEAD)
TIMESTAMP=$(date -u +%Y%m%d%H%M%S)

# بناء

aws ecr get-login-password | docker login --username AWS --password-stdin ${ECR_REGISTRY}
docker tag motanaqil/api:${TAG} ${ECR_REGISTRY}/motanaqil-api:${TAG}
docker push ${ECR_REGISTRY}/motanaqil-api:${TAG}
```

```yaml
version: '3.9'

x-common-env: &common-env
  NODE_ENV: development
  TZ: Asia/Riyadh

services:
  # ---------- PostgreSQL ----------
  postgres:
    image: postgres:15.5-alpine
    container_name: motanaqil-db
    restart: unless-stopped
    environment:
      POSTGRES_DB: motanaqil
      POSTGRES_USER: motanaqil
      POSTGRES_PASSWORD: ${DB_PASSWORD:-dev_password_change_me}
      POSTGRES_INITDB_ARGS: "--encoding=UTF-8 --lc-collate=C"
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./infra/init-db.sql:/docker-entrypoint-initdb.d/init.sql
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U motanaqil -d motanaqil"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks: [motanaqil-net]

  # ---------- Redis ----------
  redis:
    image: redis:7.2-alpine
    container_name: motanaqil-redis
    restart: unless-stopped
    command: >
      redis-server
      --requirepass ${REDIS_PASSWORD:-dev_redis_change_me}
      --appendonly yes
      --maxmemory 256mb
      --maxmemory-policy allkeys-lru
    ports:
      - "6379:6379"
    volumes:
      - redisdata:/data
    healthcheck:
      test: ["CMD", "redis-cli", "-a", "${REDIS_PASSWORD:-dev_redis_change_me}", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks: [motanaqil-net]

  # ---------- API (NestJS) ----------
  api:
    build:
      context: .
      dockerfile: apps/api/Dockerfile.dev
    container_name: motanaqil-api
    restart: unless-stopped
    environment:
      <<: *common-env
      DATABASE_URL: postgresql://motanaqil:${DB_PASSWORD:-dev_password_change_me}@postgres:5432/motanaqil
      REDIS_URL: redis://:${REDIS_PASSWORD:-dev_redis_change_me}@redis:6379
      JWT_SECRET: ${JWT_SECRET:-dev_jwt_secret_min_32_chars_change_me}
      JWT_REFRESH_SECRET: ${JWT_REFRESH_SECRET:-dev_refresh_secret_change_me}
    ports:
      - "4000:4000"
    volumes:
      - ./apps/api:/app/apps/api
      - ./packages:/app/packages
      - /app/node_modules
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_healthy
    networks: [motanaqil-net]

  # ---------- Web (Next.js) ----------
  web:
    build:
      context: .
      dockerfile: apps/web/Dockerfile.dev
    container_name: motanaqil-web
    restart: unless-stopped
    environment:
      <<: *common-env
      NEXT_PUBLIC_API_URL: http://localhost:4000
      NEXT_PUBLIC_GOOGLE_MAPS_KEY: ${NEXT_PUBLIC_GOOGLE_MAPS_KEY}
    ports:
      - "3000:3000"
    volumes:
      - ./apps/web:/app/apps/web
      - ./packages:/app/packages
      - /app/node_modules
      - /app/apps/web/.next
    depends_on: [api]
    networks: [motanaqil-net]

  # ---------- Admin (Next.js) ----------
  admin:
    build:
      context: .
      dockerfile: apps/admin/Dockerfile.dev
    container_name: motanaqil-admin
    restart: unless-stopped
    environment:
      <<: *common-env
      NEXT_PUBLIC_API_URL: http://localhost:4000
    ports:
      - "3001:3001"
    volumes:
      - ./apps/admin:/app/apps/admin
      - ./packages:/app/packages
      - /app/node_modules
    depends_on: [api]
    networks: [motanaqil-net]

  # ---------- Mailhog (لتجربة البريد محلياً) ----------
  mailhog:
    image: mailhog/mailhog:latest
    container_name: motanaqil-mailhog
    ports:
      - "1025:1025"  # SMTP
      - "8025:8025"  # Web UI
    networks: [motanaqil-net]

  # ---------- MinIO (S3 محلي) ----------
  minio:
    image: minio/minio:latest
    container_name: motanaqil-minio
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: ${MINIO_USER:-minioadmin}
      MINIO_ROOT_PASSWORD: ${MINIO_PASSWORD:-minioadmin123}
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - miniodata:/data
    networks: [motanaqil-net]

volumes:
  pgdata:
```

## 8. CI/CD Pipeline

### 8.1 GitHub Actions Workflow الكامل والآمن

```yaml
# .github/workflows/deploy.yml
name: Build, Test & Deploy

on:
  push:
    branches: [main, develop]
    tags: ['v*']
  pull_request:
    branches: [main, develop]

# صلاحيات دنيا (Zero Trust)
permissions:
  contents: read
  pull-requests: write

# منع تشغيل متزامن لنفس الفرع
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

env:
  REGISTRY: ${{ secrets.ECR_REGISTRY }}
  NODE_VERSION: '20.10'

jobs:
  # ========== 1. الفحوصات الأمنية ==========
  security:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Secret Scanning (gitleaks)
        uses: gitleaks/gitleaks-action@v2
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Dependency Audit
        run: npm audit --audit-level=high

      - name: SCA Scan (Snyk)
        uses: snyk/actions/node@master
        env:
          SNYK_TOKEN: ${{ secrets.SNYK_TOKEN }}
        continue-on-error: true

      - name: SAST (CodeQL)
        uses: github/codeql-action/init@v3
        with:
          languages: javascript
      - uses: github/codeql-action/analyze@v3

  # ========== 2. الاختبارات ==========
  test:
    needs: security
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:15.5-alpine
        env:
          POSTGRES_DB: test
          POSTGRES_USER: test
          POSTGRES_PASSWORD: test
        ports: ['5432:5432']
        options: >-
          --health-cmd pg_isready --health-interval 10s --health-timeout 5s --health-retries 5
      redis:
        image: redis:7.2-alpine
        ports: ['6379:6379']
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: 'npm'
      - run: npm ci
      - run: npx prisma generate
      - run: npx prisma migrate deploy
        env:
          DATABASE_URL: postgresql://test:test@localhost:5432/test
      - run: npm run lint
      - run: npm run type-check
      - run: npm run test:unit -- --coverage
      - run: npm run test:integration
        env:
          DATABASE_URL: postgresql://test:test@localhost:5432/test
          REDIS_URL: redis://localhost:6379
      - uses: actions/upload-artifact@v4
        with:
          name: coverage
          path: coverage/

  # ========== 3. البناء والدفع ==========
  build:
    needs: test
    if: github.event_name == 'push'
    runs-on: ubuntu-latest
    # OIDC للـ AWS (لا مفاتيح طويلة العمر)
    permissions:
      id-token: write
      contents: read
    outputs:
      tag: ${{ steps.meta.outputs.tag }}
    steps:
      - uses: actions/checkout@v4

      - name: Configure AWS (OIDC)
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: ${{ secrets.AWS_DEPLOY_ROLE }}
          aws-region: me-central-1

      - name: Login to ECR
        uses: aws-actions/amazon-ecr-login@v2

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3

      - name: Compute tag
        id: meta
        run: |
          TAG="${GITHUB_REF_NAME}-${GITHUB_SHA::7}"
          echo "tag=${TAG}" >> $GITHUB_OUTPUT

      - name: Build & Push API
        uses: docker/build-push-action@v5
        with:
          context: .
          file: apps/api/Dockerfile
          push: true
          tags: |
            ${{ env.REGISTRY }}/motanaqil-api:${{ steps.meta.outputs.tag }}
          cache-from: type=gha
          cache-to: type=gha,mode=max
          # لا أسرار في الصورة
          build-args: |
            BUILD_COMMIT=${{ github.sha }}

      - name: Scan Image (Trivy)
        uses: aquasecurity/trivy-action@master
        with:
          image-ref: ${{ env.REGISTRY }}/motanaqil-api:${{ steps.meta.outputs.tag }}
          severity: 'CRITICAL,HIGH'
          exit-code: '1'

      # (تكرار للـ web و admin بنفس النمط)

  # ========== 4. النشر لـ Staging ==========
  deploy-staging:
    needs: build
    if: github.ref == 'refs/heads/develop'
    runs-on: ubuntu-latest
    environment: staging   # GitHub Environment مع حماية
    permissions:
      id-token: write
      contents: read
    steps:
      - uses: actions/checkout@v4
      - name: Configure AWS (OIDC)
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: ${{ secrets.AWS_DEPLOY_ROLE }}
          aws-region: me-central-1
      - name: Deploy to Staging
        run: |
          aws eks update-kubeconfig --name motanaqil-staging --region me-central-1
          helm upgrade --install motanaqil ./helm/motanaqil \
            --namespace motanaqil-staging \
            --set api.image.tag=${{ needs.build.outputs.tag }} \
            --set web.image.tag=${{ needs.build.outputs.tag }} \
            --wait --timeout 10m
      - name: Run Smoke Tests
        run: npm run test:smoke -- --env=staging

  # ========== 5. النشر للإنتاج (يدوي + موافقة) ==========
  deploy-production:
    needs: [build, deploy-staging]
    if: startsWith(github.ref, 'refs/tags/v')
    runs-on: ubuntu-latest
    environment:
      name: production
      # يتطلب موافقة 2 من المدراء + نافذة نشر
    permissions:
      id-token: write
      contents: read
    steps:
      - uses: actions/checkout@v4
      - name: Configure AWS (OIDC)
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: ${{ secrets.AWS_PROD_ROLE }}
          aws-region: me-central-1
      - name: Backup DB before deploy
        run: ./scripts/backup-db.sh
      - name: Run Migrations
        run: ./scripts/migrate-prod.sh
      - name: Deploy (Blue-Green)
        run: ./scripts/blue-green-deploy.sh ${{ needs.build.outputs.tag }}
      - name: Post-deploy Health Check
        run: ./scripts/health-check.sh
      - name: Notify (Slack/Email)
        if: always()
        run: ./scripts/notify-deploy.sh ${{ job.status }}
```

```nginx
# /etc/nginx/conf.d/motanaqil.conf

# Upstreams
upstream api_backend {
    least_conn;
    server api-1.motanaqil.local:4000 max_fails=3 fail_timeout=30s;
    server api-2.motanaqil.local:4000 max_fails=3 fail_timeout=30s;
    server api-3.motanaqil.local:4000 max_fails=3 fail_timeout=30s;
    keepalive 64;
}

upstream web_backend {
    server web-1.motanaqil.local:3000;
    server web-2.motanaqil.local:3000;
    keepalive 32;
}

upstream admin_backend {
    server admin-1.motanaqil.local:3001;
    keepalive 16;
}

# Rate limiting zones
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=50r/s;
limit_req_zone $binary_remote_addr zone=auth_limit:10m rate=5r/m;
limit_req_zone $binary_remote_addr zone=upload_limit:10m rate=1r/s;
limit_conn_zone $binary_remote_addr zone=conn_limit:10m;

# Redirect HTTP → HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name motanaqil.com www.motanaqil.com api.motanaqil.com admin.motanaqil.com;
    return 301 https://$host$request_uri;
}

# ---------- Main Web ----------
server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name motanaqil.com www.motanaqil.com;

    # SSL (قسم 10)
    include /etc/nginx/snippets/ssl-params.conf;
    ssl_certificate     /etc/letsencrypt/live/motanaqil.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/motanaqil.com/privkey.pem;

    # Security Headers (موحّد مع ملف 09)
    include /etc/nginx/snippets/security-headers.conf;

    # Limits
    limit_conn conn_limit 50;
    client_max_body_size 20m;

    # Gzip
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml image/svg+xml;

    # Static assets (cache طويل)
    location /_next/static/ {
        proxy_pass http://web_backend;
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    location /images/ {
        proxy_pass http://web_backend;
        expires 30d;
        add_header Cache-Control "public";
    }

    # WebSocket (التتبع الفوري)
    location /socket.io/ {
        proxy_pass http://api_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400;
    }

    # API
    location /api/ {
        limit_req zone=api_limit burst=100 nodelay;
        proxy_pass http://api_backend;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Request-ID $request_id;
        proxy_connect_timeout 10s;
        proxy_read_timeout 60s;
    }

    # Auth endpoints (rate limit أشد)
    location ~ ^/api/v1/auth/(login|register|forgot-password|otp) {
        limit_req zone=auth_limit burst=5 nodelay;
        proxy_pass http://api_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # Upload (rate limit خاص)
    location ~ ^/api/v1/.*/upload {
        limit_req zone=upload_limit burst=5;
        client_max_body_size 20m;
        proxy_pass http://api_backend;
        proxy_set_header Host $host;
        proxy_read_timeout 120s;
    }

    # Web App
    location / {
        proxy_pass http://web_backend;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # إخفاء ملفات حساسة
    location ~ /\.(env|git|htaccess) { deny all; return 404; }

    # Health (لا يُسجّل)
    location = /nginx-health { access_log off; return 200 "ok"; }
}

# ---------- Admin (مع IP allowlist اختياري) ----------
server {
    listen 443 ssl http2;
    server_name admin.motanaqil.com;
```

```bash
# scripts/blue-green-deploy.sh
set -euo pipefail

NEW_TAG=$1

  echo "❌ Health check failed. Aborting, keeping $CURRENT_COLOR"
  kubectl delete deployment motanaqil-api-${NEW_COLOR} -n motanaqil-prod
  exit 1
fi

# 4. تحويل الحركة (تبديل الـ Service selector)
kubectl patch svc motanaqil-api -n motanaqil-prod \
  -p "{\"spec\":{\"selector\":{\"color\":\"${NEW_COLOR}\"}}}"

# 5. مراقبة الأخطاء لمدة 5 دقائق
sleep 300
if ./scripts/error-rate-check.sh; then
  echo "✅ Deployment successful. Cleaning up $CURRENT_COLOR"
  kubectl delete deployment motanaqil-api-${CURRENT_COLOR} -n motanaqil-prod
else
  echo "⚠️ High error rate. Rolling back to $CURRENT_COLOR"
  kubectl patch svc motanaqil-api -n motanaqil-prod \
    -p "{\"spec\":{\"selector\":{\"color\":\"${CURRENT_COLOR}\"}}}"
  exit 1
fi
```

## 18. Zero-Downtime Deployment

### 18.1 Graceful Shutdown

```typescript
// main.ts - معالجة SIGTERM بشكل صحيح
async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  // ... setup
  
  // Graceful shutdown
  app.enableShutdownHooks();
  
  const server = await app.listen(4000);
  
  const shutdown = async (signal: string) => {
    logger.log(`Received ${signal}, starting graceful shutdown...`);
    
    // 1. إيقاف استقبال طلبات جديدة
    server.close(() => logger.log('HTTP server closed'));
    
    // 2. انتظار الطلبات الجارية (مع مهلة)
    await Promise.race([
      app.close(),
      new Promise(resolve => setTimeout(resolve, 30000)), // 30s max
    ]);
    
    // 3. إغلاق الاتصالات (DB, Redis, queues)
    await prisma.$disconnect();
    await redis.disconnect();
    await queue.close();
    
    logger.log('Graceful shutdown complete');
    process.exit(0);
  };
  
  process.on('SIGTERM', () => shutdown('SIGTERM'));
  process.on('SIGINT', () => shutdown('SIGINT'));
}
```

```typescript
    return { status: 'ok', timestamp: new Date().toISOString() };
  }

  // Readiness: هل جاهز لاستقبال حركة؟
  @Get('ready')
  async ready(@Res() res: Response) {
    const checks = await Promise.allSettled([
      this.prisma.$queryRaw`SELECT 1`,
      this.redis.ping(),
    ]);
    
    const healthy = checks.every(c => c.status === 'fulfilled');
    
    return res.status(healthy ? 200 : 503).json({
      status: healthy ? 'ready' : 'not_ready',
      database: checks[0].status === 'fulfilled',
      redis: checks[1].status === 'fulfilled',
    });
  }

  // تفصيلي (للإدارة فقط، محمي)
  @Get('detailed')
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles('admin', 'super_admin')
  async detailed() {
    return {
      version: process.env.npm_package_version,
      commit: process.env.BUILD_COMMIT,
      uptime: process.uptime(),
      memory: process.memoryUsage(),
      connections: await this.getConnectionStats(),
    };
  }
}
```

## 26. Runbooks التشغيلية

### 26.1 Runbook: ارتفاع معدل الأخطاء

```markdown
# Runbook: High Error Rate (5xx)

## الكشف
- تنبيه HighErrorRate من CloudWatch/Sentry

## التشخيص الفوري
1. افتح Grafana dashboard → أي endpoint متأثر؟
2. افتح Sentry → ما هو الخطأ المتكرر؟
3. افحص السجلات: `kubectl logs -l app=motanaqil-api --tail=200 | grep ERROR`
4. افحص التبعية: هل DB/Redis بطيء؟ (CloudWatch RDS/ElastiCache)

## الإجراءات حسب السبب
- **كود معطوب في نشر حديث** → Rollback فوري (قسم 19)
- **DB overload** → فحص queries بطيئة، قتل long queries، توسع read replica
- **Redis down** → فحص ElastiCache، failover
- **مزود خارجي down** → تفعيل circuit breaker، fallback
- **حركة غير طبيعية (هجوم)** → تفعيل WAF rules، حظر IPs

## بعد الحل
- مراقبة 30 دقيقة
- تقرير incident (قسم 18 في ملف 09)
```

### 26.2 Runbook: قاعدة البيانات بطيئة

```markdown
# Runbook: Database Performance Degradation

1. فحص RDS metrics: CPU, IOPS, connections, lock waits
2. فحص Performance Insights → top queries
3. قتل queries طويلة: `SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE state='idle in transaction' AND query_start < now() - interval '5 minutes'`
4. فحص missing indexes (EXPLAIN ANALYZE)
5. فحص connection leaks في التطبيق
6. إن لزم: إضافة read replica / ترقية instance
```

### 26.3 Runbook: نفاد المساحة

```markdown
# Runbook: Disk Space Low

1. تحديد المسار: `df -h` / CloudWatch
2. DB: RDS storage autoscaling (إن مفعّل) أو ترقية يدوية
3. Logs: تدوير السجلات، تقليل retention، أرشفة القديم
4. تنظيف: صور مؤقتة، cache، old backups محلية
5. طويل الأمد: lifecycle policies، monitoring أفضل
```
